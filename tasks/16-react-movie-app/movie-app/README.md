# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.

# Learn to Code

A structured, hands-on curriculum to learn web development from absolute zero to deploying your own app.

Each task builds on the previous one, and you'll go from writing your first line of HTML to deploying a full Next.js application on Vercel.

## How to Use This Repo

1. **Start with Task 01** and work your way up in order
2. Each task has its own folder inside `tasks/` with a `TASK.md` file
3. Read the task description carefully before starting
4. Create your solution files directly in the task folder
5. When you finish a task, commit your work and move to the next one
6. **You have Claude Code** - use it when you're stuck (each task has specific hints)

## Prerequisites

- A computer (Mac, Windows, or Linux)
- [VS Code](https://code.visualstudio.com/) installed (or any text editor)
- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) installed and set up
- A web browser (Chrome recommended for DevTools)
- A [GitHub](https://github.com) account
- Curiosity and patience!

## Tips for Success

- **Don't skip tasks.** Each one builds skills you'll need later.
- **Type the code yourself.** Don't copy-paste - typing helps you learn.
- **Break things on purpose.** Change values, delete lines, see what happens. That's how you learn.
- **Use Claude Code wisely.** Try to solve problems yourself first. When you're stuck for 10-15 minutes, ask Claude for help. But always try to understand the answer, don't just copy it.
- **Google is your friend.** Professional developers Google things every day. It's not cheating.
- **Commit often.** Save your progress with Git after each meaningful change.

## Estimated Timeline

- If you code **1-2 hours daily**: ~4-6 weeks
- If you code **3-4 hours daily**: ~2-3 weeks
- Take your time - understanding is more important than speed!
